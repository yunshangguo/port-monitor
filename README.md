# 本机端口监控工具

检测本机端口使用情况：**端口是否被占用、被哪个程序占用**（进程名 / PID / 程序路径 / 命令行）。常驻系统托盘，提供桌面应用窗口和网页两种视图。

## 已实现功能

- **系统托盘常驻**：启动后缩到右下角托盘，双击图标打开监控界面，右键菜单含「打开监控界面 / 设置 / 开机自启动 / 退出」
- **关窗不退出**：关闭监控窗口只是关掉窗口，程序继续在托盘后台运行，双击托盘图标可再次打开
- **开机自启动**：设置里一键开启，写入当前用户的开机启动项
- **设置面板**：页面右上角 ⚙ 或托盘右键「设置」，可调自动刷新间隔、开机自启、开机时是否自动打开界面，设置自动保存
- **穿插式统一视图**：程序占用块与空闲端口在同一条序列里按端口号顺序穿插排列。彩色块=程序占用，采用大卡片样式（大图标 + 程序名 + 端口标签），同一程序占用的多个端口合并进一个块；灰色块=连续未使用的端口（标注范围与数量）
- **默认全部端口、无分页**：打开即展示 1-65535 全部端口，连续未使用端口默认合并为灰色区间块；页面纵向自然铺开
- **统计口径一致**：「已用端口 / 空闲端口」均按全部 1-65535 统计，两者相加恒等于 65535
- 程序识别：进程名、PID、可执行文件路径、启动命令行；端口查询支持监听与活动连接
- **查询即跳转**：输入端口查询后自动滚动到该端口位置并高亮；占用端口精确定位到标签，空闲端口高亮其所在的灰色区间块（保持折叠），高亮在自动刷新后仍保持
- **回到顶部**：页面右侧悬浮「顶部 ↑」按钮，滚动超过一屏后出现
- 持续监控：默认每 3 秒自动刷新，新增端口标绿、消失标红（消失项保留 3 次刷新）

## 快速开始（推荐：exe 版，无需 Python）

双击 `dist\端口监控.exe` 即可：程序启动后常驻右下角托盘，并自动打开监控窗口。

- **双击托盘图标**：打开/切换监控界面
- **右键托盘图标**：打开监控界面 / 设置 / 开机自启动 / 退出
- **关闭监控窗口**：程序不退到托盘后台继续运行，双击托盘图标可再打开
- **真正退出**：右键托盘图标 → 退出

网页地址：<http://127.0.0.1:8765>（同一局域网的其他机器无法访问，仅本机）

### 重新打包

修改源码后双击 `打包exe.bat`，重新生成 `dist\端口监控.exe`（单文件、无控制台黑框）。

## 源码运行（需 Python）

需要 Python 3.9+，依赖：`psutil`、`pystray`、`Pillow`。桌面窗口用系统自带的 Edge/Chrome，无需额外库。

```bash
python -m pip install -r requirements.txt
python main.py                      # 托盘常驻模式（默认）
python main.py --mode web           # 仅网页服务，不开托盘
python main.py --no-window          # 托盘启动但不自动弹窗
python main.py --port 9000          # 指定网页端口
```

对应的 bat：`启动_双模式.bat`（托盘+窗口）、`启动_网页版.bat`（仅网页）、`安装依赖.bat`。

## 设置与配置

设置保存在 **exe 所在文件夹的 `config.json`**（源码运行时在项目根目录），程序运行时产生的持久文件只有这一个，全部集中在程序目录，不往系统其他位置写。开机自启写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `PortMonitor` 项，在设置面板里改自启开关会同步更新注册表。

从旧版本升级时，会自动把原先存在 `%APPDATA%\PortMonitor\config.json` 的配置迁移到 exe 目录，已设置好的参数不会丢失。若 exe 放在只读目录导致配置无法写入，会自动回退到 APPDATA，避免程序崩溃。

设置在**保存后立即生效**：刷新间隔会实时重建页面轮询（不用重启程序），保存后面板会显示「设置已保存」提示；下次启动程序时自动读回上次的配置，无需重复设置。若程序已在托盘运行，再次双击 exe 会直接打开已有界面，不会因端口占用而静默退出。

## 登录与加密（远程访问安全）

默认**本机 127.0.0.1 访问免登录**，局域网其它设备访问必须登录，防止宿主机的端口/进程/命令行信息外泄。

- **初始账号密码**：程序目录（exe 同文件夹）下的 `初始登录信息.txt`，首次启动自动生成随机密码。请尽快在「设置 → 账号与安全 → 修改密码」改成自己的密码；改完该文件自动失效，所有登录会话也会立即清空。
- **防暴力破解**：连续输错 5 次密码，锁定该来源 60 秒。
- **HTTPS 加密**：设置里打开「启用 HTTPS 加密」→ 保存 → 右键托盘退出 → 重新启动程序，之后用 `https://设备IP:8765` 访问。传输全程 TLS 加密，防局域网抓包。
  - 用的是内置自签证书，浏览器首次访问会提示「连接不是私密连接」，属正常现象：点「高级」→「继续前往」信任一次即可（Chrome/Edge）。
  - HTTPS 开关需重启才生效；关闭后恢复 `http://` 访问。
- **远程访问需登录**开关：默认开启。除非确定局域网绝对可信，否则不要关闭。

> 提示：本机自己用 127.0.0.1 访问时，无论登录开关如何都无需密码，方便日常使用。

## 项目结构

```
端口检测工具/
├── main.py                       入口（托盘 / 网页模式）
├── app.ico                       应用与托盘图标
├── 打包exe.bat                   一键打包为 exe
├── requirements.txt              依赖清单
├── port_monitor/
│   ├── core.py                   端口与进程采集、查询、快照比对
│   ├── web.py                    本地 HTTP/HTTPS 服务、JSON 接口、登录鉴权
│   ├── web_page.html             监控界面、设置面板、登录页
│   ├── desktop.py                桌面应用窗口（独立进程）
│   ├── tray.py                   系统托盘与右键菜单
│   ├── config.py                 配置持久化、开机自启、密码哈希
│   ├── server.crt / server.key   内置 HTTPS 自签证书
│   └── __pycache__/
├── dist/
│   ├── 端口监控.exe              打包成品
│   ├── config.json               运行时配置（首次启动自动生成）
│   └── 初始登录信息.txt          首次启动随机密码（改密码后失效）
└── 初始登录信息.txt / config.json  源码运行时的产物（源码模式用项目根）
```
